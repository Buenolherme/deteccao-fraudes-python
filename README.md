# deteccao-fraudes-python
# Detecção de Fraudes em Cartão de Crédito

Projeto de Machine Learning desenvolvido em Python utilizando Google Colab.

## Tecnologias
- Python
- Pandas
- Scikit-Learn
- Google Colab

## Objetivo
Detectar transações fraudulentas usando algoritmos de classificação.

## Etapas
- Carregamento do dataset
- Análise dos dados
- Separação treino/teste
- Treinamento do modelo
- Avaliação de métricas

## Resultado
O modelo conseguiu identificar fraudes com boa precisão e recall.
